Los diferentes tipos de bases de datos que hay, indicando ejemplo para cada tipo

BASES DE DATOS ESTÁTICAS Y DINÁMICAS

Las bases de Datos Dinámicas y Estáticas que se basan en cómo se comporta la información registrada. La diferencia reside en que en las Estáticas no se suele modificar la información, mientras que en las Dinámicas; como su nombre indica, dicha información se modifica con cierta frecuencia.

BASES DE DATOS DE TEXTO COMPLETO / BIBLIOGRÁFICAS / DIRECTORIOS

En las bases de datos de texto completo se suelen registrar todo el texto que se va a consultar, así se puede hacer una investigación extensa. En las bibiográficas, la información almacenada puede dar una noción de qué va el tema, una pincelada de lo que se puede investigar luego. Y por último, los directorios son solo se usa para orgaizar la información básica.

RELACIONALES / NO RELACIONALES / ORIENTADAS A OBJETOS / MULTIDIMENSIONALES / DEDUCTORES / JERÁRQUICAS

Las relacionales son aquellas que guardan la información en formato tablas. Las No relacionales guardan gran cantidad de información, pero al contrario de las relacionales, no siguen un orden fijo. Por otro lado, la Orientada a Objetos guarda las piezas completas de la información, las Multidimensionales organizan los datos en formato capas para que puedan ser analizadas desde muchos puntos de vista y por último las deductivas usan la lógica para sacra conslusiones nuevas a partir de los datos que ya se tiene, y las jerárquicas organizan todo los niveles de importancia.

EJEMPLOS:

Relacionales - Un Banco

No Relacionales - Instagran (Cualquier red social)

Relacionales - Un VideoJuego

Multidimensional- Un Supermercado

Deductivas- Una aplicación que mide cuántas calorias deberías consumir

Jerárquicas - Un sistema de Archivado, por ejemplo del ordenador
